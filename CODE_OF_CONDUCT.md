# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation in VNKC a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Standards

- Be respectful and constructive; critique work, not people.
- Vietnamese and English are both welcome in project spaces. Write so others can follow; translation help is a contribution, not a burden.
- Data disputes are settled with citations, not rhetoric — the authoritative source wins.

## Enforcement

Report unacceptable behavior to the maintainers via GitHub (open an issue or use the contact in [SECURITY.md](./SECURITY.md)). Reports are handled confidentially. Maintainers may remove content or ban participants who violate this code, per the Contributor Covenant enforcement guidelines.
