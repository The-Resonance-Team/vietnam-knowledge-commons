# Data

This directory contains ephemeral working data. **Not committed to git.**

- `raw/` — Scraper output before any processing
- `interim/` — Partially processed, not yet validated
- `canonical/` — Schema-validated records (working copy)
- `derived/` — Transformed outputs for dataset publication
- `samples/` — Example records committed for reference

Published datasets live in `datasets/` (committed).
